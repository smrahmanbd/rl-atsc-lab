Foundation · the lecture's Q-learning example

Five rooms and a way out

An agent is dropped in a room and has to learn the way outside (room 5). Going through a door that leads outside earns 100 points; every other door earns 0. Move it yourself and watch the Q matrix fill in, or let it practise.

Rows are the state (the room the agent is in). Columns are the action (the room it goes to). −1 means there is no door.

Best route from each room

Follow the highest Q value in each row. Before training, the agent has no route.

The rule being applied

Q(state, action) = R(state, action) + γ × max Q(next state, all actions)

This is the deterministic form used in the lecture example. Each move updates one entry of Q. Entries near the exit learn first, and the values spread backwards from room to room with further episodes. The lecture slides walk through the first two updates by hand.
